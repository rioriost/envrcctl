# envrcctl 0.3.2 — predictable Homebrew installation

Fix Homebrew installation failures caused by pip trying to download undeclared build dependencies such as `flit_core` from PyPI during installation.

The formula now uses the universal Python wheels and SHA-256 hashes recorded in `uv.lock`, plus the release's own wheel. Homebrew fetches and verifies all packages before installation. Pip installs only these local files, with its package index and build isolation disabled. No additional PyPI access is required during the installation phase.

Dependency versions and their configured download sources are unchanged. Downloads still need to be permitted by the device's network policy; no management or security settings are modified.

The Apple Silicon authentication helper remains a separate signed and notarized release asset. The Python wheel explicitly excludes this native helper.
