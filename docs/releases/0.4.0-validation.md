## Validation boundaries

Tests did not access real envrcctl-managed application secrets or invoke Touch ID/
Apple Watch prompts. Native authentication protocols use synthetic tests;
existing Keychain ACL interoperability and a live Linux SecretService session
were not exercised. Signing and notarization used the operator's existing
authorized credentials through the OS tools without exposing passwords.

Publication targets are GitHub Release assets and the Homebrew tap. This
validation does not claim a PyPI upload.
